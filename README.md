# machine-learning-deeplearning.ai
Labs for machine learning specialization from DeepLearning.AI. It teaches foundational AI concepts through an intuitive visual approach, before introducing the code needed to implement the algorithms and the underlying math.

The labs using python via Jupyter notebook, or ipython notebook, as they are a web-based interface in which you can write, visualise and execute python code in cells.

To use, download the file, and open it via Jupyter online IDE or browser via Jupyter Notebook website: https://jupyter.org/
